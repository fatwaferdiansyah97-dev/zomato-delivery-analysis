# Zomato Delivery Analysis

Take home test, Data Analyst Bootcamp (Dibimbing).

Goal: identify the factors behind late food deliveries (more than 30 minutes) and recommend operational actions.

Files:
- Zomato_Delivery_Analysis.ipynb: data cleaning, feature engineering, and EDA (Python)
- Zomato_Delivery_Dashboard.pbix: interactive Power BI dashboard
- zomato_clean.csv: cleaned dataset used by the dashboard
- PDF: presentation slides

Dataset: Zomato Delivery Operations Analytics (Kaggle), 45,584 orders, Feb to Apr 2022.
